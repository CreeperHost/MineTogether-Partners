# MineTogether Partners

MineTogether Partners - empower pack creators
 

MineTogether Partners adds optional tools for CreeperHost partners and pack developers.
It allows verified partners to include server rental and referral options directly inside their modpacks using their CreeperHost partner code.

This system gives creators a fair way to earn from their work, without intrusive monetisation or forced visibility.
Players only see the options if a pack creator has enabled them inside their pack.

Features

- Optional partner interface inside Minecraft menus

- Connects securely to CreeperHost’s partner API

- Lets pack creators include their partner code for sales tracking

- Supports clear, dismissible presentation - no forced ads

- Respects player privacy and never tracks gameplay data

- Fully compatible with MineTogether Community and MineTogether Server Listing for full integration
